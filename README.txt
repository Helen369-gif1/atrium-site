АТРИУМ 210° — как запустить и что где менять

ЗАПУСК
  Откройте папку в VS Code → правый клик на index.html → Open with Live Server.
  (Двойной клик по файлу не подойдёт: браузер не даст загрузить картинку с диска.)
  Интернет не нужен: библиотека, шрифты и картинки лежат внутри.

ЧТО МЕНЯТЬ — всё в начале файла atrium.js, блок ATRIUM:
  title / signature   — заголовок сверху и подпись под ним
  hint / hintTouch    — подсказка внизу (компьютер / телефон)
  rooms[].name        — название комнаты (в подсказке и на экране комнаты)
  rooms[].inscription — надпись на табличке над аркой, по строкам: ['Global', 'Reserve']
  rooms[].href        — ссылка, куда вести по клику. null — показать экран-заглушку
  rooms[].text        — (можно добавить) текст на экране комнаты
  rooms[].video       — видео, которое играет после входа (сейчас у Global Reserve)
  rooms[].door / plaque — координаты проёма и таблички в пикселях картинки 6516×2172.
                        Менять только если заменили картинку на другую.

ЗАМЕНА КАРТИНКИ
  Положите новые файлы в assets/ (большой ≈6500 px и половинный для телефонов)
  и поправьте image.full / image.small. Если проёмы сдвинулись — нужны новые координаты.

УПРАВЛЕНИЕ
  Мышь/палец — тянуть; колесо или два пальца — приближение;
  стрелки — поворот; Tab — переход по проёмам; Enter — войти; Esc — выйти из комнаты.
